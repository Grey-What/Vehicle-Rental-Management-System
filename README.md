# Vehicle Rental Management System

Develop a console-based Vehicle Rental Management System using Qt 6 (Qt 
Core). The goal is to demonstrate Object-Oriented Programming (OOP) principles 
(encapsulation, inheritance, polymorphism, abstraction), menu-driven interaction, 
file handling, and rental/return state management. 

### Running Program:
Open the Cmake file in QT Creator

0. Ensure the following settings:
    - Ensure In Qt Creator:
    - Projects
        - Run
        - Check: 'Run in terminal'
        

1. navigate to main file 'main.cpp'

2. Ctrl R
